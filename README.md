# 3D TicTacToe – iOS

An **iOS implementation of my 3D TicTacToe game**, developed in **Swift using Xcode**.

The game is based on the same rules and game modes as my Python/Pygame version, but was redesigned as a native iOS application.

## Game

The computer player uses the **Minimax algorithm**, as in the original Python implementation.

For a detailed description of the **game rules, game modes, and gameplay**, see the README of the Python version:

👉 [3D TicTacToe – Python/Pygame](https://github.com/DomiHuber/3D-TicTacToe)

##  Technologies

- **Swift**
- **Xcode**
- iOS
